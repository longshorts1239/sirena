# ⚖️ Νομοθεσίων — Ελληνική Νομοθεσία

Δομημένο, ελεύθερο **ευρετήριο της βασικής ελληνικής νομοθεσίας** για φοιτητές
της Νομικής και για δικηγόρους / νομικούς. Οργανώνει το Σύνταγμα, τους Κώδικες
και τους θεμελιώδεις νόμους κάθε κλάδου δικαίου σε **κατηγορίες**, με **άμεση
αναζήτηση** και συνδέσμους στα επίσημα πλήρη κείμενα.

> Ιστότοπος 100% στατικός (HTML/CSS/JavaScript) — χωρίς backend, χωρίς
> εξαρτήσεις, χωρίς βήμα build. Ανοίγει και τοπικά με διπλό κλικ στο `index.html`.

---

## ✨ Χαρακτηριστικά

- **20 κατηγορίες δικαίου** (Αστικό, Ποινικό, Εμπορικό, Εργατικό, Φορολογικό,
  Διοικητικό, Ευρωπαϊκό, Προστασία Δεδομένων, Μετανάστευση κ.ά.).
- **Έξυπνη αναζήτηση** ανά τίτλο, αριθμό νόμου, θέμα ή λέξη-κλειδί, **ανεξάρτητη
  τόνων και πεζών/κεφαλαίων** (π.χ. `ποινικος` βρίσκει «Ποινικός Κώδικας»).
- **Φιλτράρισμα** ανά κατηγορία και επισήμανση των όρων αναζήτησης.
- **Σύνδεσμοι πλήρους κειμένου** προς επιλεγόμενη πηγή (Google, kodiko.gr,
  e-nomothesia.gr, Εθνικό Τυπογραφείο).
- **Αντιγραφή παραπομπής** με ένα κλικ.
- **Φωτεινό & σκοτεινό θέμα**, πλήρως **responsive** (κινητό/tablet/desktop).
- **Κοινοποιήσιμοι σύνδεσμοι**: η αναζήτηση & η κατηγορία αποθηκεύονται στο URL
  (π.χ. `index.html#q=διαζύγιο`, `index.html#cat=criminal`).
- Συντομεύσεις πληκτρολογίου: `/` εστίαση στην αναζήτηση, `Esc` καθαρισμός.

## 🚀 Χρήση

Ανοίξτε απλώς το `index.html` σε οποιονδήποτε browser. Δεν απαιτείται
εγκατάσταση. Για τοπικό server (προαιρετικά):

```bash
python3 -m http.server 8000
# άνοιγμα http://localhost:8000
```

## ➕ Πώς να προσθέσετε ή να επεξεργαστείτε νόμους

Όλα τα δεδομένα βρίσκονται στο **`data/legislation.js`**. Δεν χρειάζεται να
αγγίξετε τον υπόλοιπο κώδικα.

Προσθέστε ένα αντικείμενο στον πίνακα `LAWS`:

```js
{
  id: "n-1234-2025",            // μοναδικό αναγνωριστικό
  type: "Νόμος",                // Νόμος | Κώδικας | Π.Δ. | Σύνταγμα | Κανονισμός ΕΕ ...
  number: "1234/2025",          // επίσημη αρίθμηση
  abbr: "ν. 1234/2025",         // (προαιρετικό) σύντμηση
  title: "Τίτλος του νόμου",
  category: "civil",            // id κατηγορίας από τον πίνακα CATEGORIES
  year: 2025,
  fek: "ΦΕΚ Α΄ 10/01.01.2025",  // (προαιρετικό) αναφορά ΦΕΚ
  tags: ["λέξη", "θέμα"],       // (προαιρετικό) για καλύτερη αναζήτηση
  summary: "Σύντομη περιγραφή."  // (προαιρετικό)
}
```

Για **νέα κατηγορία**, προσθέστε αντικείμενο στον πίνακα `CATEGORIES`
(`id`, `icon`, `label`, `desc`) και χρησιμοποιήστε το `id` στους νόμους.

## 🌐 Δημοσίευση (GitHub Pages)

1. Κάντε push το repository στο GitHub.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Επιλέξτε branch (π.χ. `main`) και φάκελο `/ (root)` → **Save**.
4. Ο ιστότοπος θα είναι διαθέσιμος στο `https://<user>.github.io/<repo>/`.

Το αρχείο `.nojekyll` διασφαλίζει τη σωστή εξυπηρέτηση των στατικών αρχείων.

## ⚠️ Νομική σημείωση

Το περιεχόμενο παρέχεται **αποκλειστικά για εκπαιδευτική και ενημερωτική
χρήση**, «ως έχει», χωρίς εγγύηση πληρότητας ή επικαιρότητας, και **δεν αποτελεί
νομική συμβουλή** ούτε υποκαθιστά τις επίσημες πηγές. Πρόκειται για **δομημένο
ευρετήριο** των βασικών νομοθετημάτων — όχι για πλήρες αρχείο κάθε ΦΕΚ. Για
κάθε επίσημη χρήση επαληθεύετε το πλήρες, επικαιροποιημένο κείμενο στις επίσημες
πηγές:

- [Εθνικό Τυπογραφείο (ΦΕΚ)](https://www.et.gr/)
- [Βουλή των Ελλήνων](https://www.hellenicparliament.gr/Nomothetiko-Ergo/Anazitisi-Nomothetikou-Ergou)
- [kodiko.gr](https://www.kodiko.gr/) · [e-nomothesia.gr](https://www.e-nomothesia.gr/)

Οι αναφορές ΦΕΚ στη βάση δεδομένων είναι ενδεικτικές.
